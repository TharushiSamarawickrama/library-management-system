# Library Management System

This is a Laravel-based Library Management System developed using Laravel, Blade frontend, and MySQL database.

## Features

- Admin and normal user roles
- Book management
- Add, view, edit, and delete books
- User registration and login
- MySQL database with Laravel migrations

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML/CSS
- Git and GitHub
